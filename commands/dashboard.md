# XSlop dashboard

Build or review product UI. Load `modes/operate.md`, `rules/product/dashboards.md`,
`inspiration/dashboards.md` and `recipes/dashboard.md`.

- Ask (or read from `PRODUCT.md`) the main question the dashboard answers and who asks it how often.
- Design the shell first: navigation, page header with primary action, work areas (`DB-02`).
- Lead with the answer to the main question, then supporting data (`DB-05`, `DB-06`).
- Choose each chart by the question it answers (`DB-07`, `DB-08`), each table by `DB-09`.
- Build loading, empty, error and partial-failure states for every widget (`DB-11` to `DB-13`).
- Use realistic demo data with one interesting state (`DB-18`).
- Review: with the logo covered, is it at least as clean as the best product in the category?
