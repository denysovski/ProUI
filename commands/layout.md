# XSlop layout

A spacing, grid and hierarchy pass. Load `rules/design/layout.md`.

- Squint test on each viewport: one focal point, then clear groups (`LY-02`).
- Every spacing value on the 4 px scale (`LY-05`); groups separated by about twice their inner spacing
  (`LY-06`).
- Vary section rhythm and composition (`LY-07`, `LY-12`).
- Alignment to the grid, optical alignment for icons and play buttons (`LY-10`, `DC-17`).
- Responsive structure at 360, 390, 768, 1024, 1440, 1920 px; container queries for reusable components
  (`LY-14`, `LY-15`).
