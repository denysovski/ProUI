# ProUI effects

Pick and install effects for a site, or review the ones it has. Load `effects/README.md`, `effects/levels.md`,
`effects/presets.md` and `rules/effects/README.md`.

- Read the effect level and feel from `proui/DECISIONS.md`. If they are missing, ask the effect-level and feel
  questions from `templates/workflow/INTAKE.md` first.
- Take the preset row for the chosen style keyword and the user's request ("modern web", "3D effects",
  "gradients"), and keep only what the level allows.
- Present two or three named combinations, each with its components linked to the catalogue
  (`effects/catalog/react-bits.md`, `effects/catalog/21st-3d.md`), what renders with WebGL, and the expected
  weight. Let the user choose.
- Install from the registry (`effects/install.md`), restyle to tokens, remove demo content.
- Apply the Effects Rulebook: lazy loading, visibility pause, pixel-ratio cap, fallback, reduced motion.
- Record the components, sources and licences in `proui/DECISIONS.md`.
