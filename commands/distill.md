# ProUI distill

Remove what does not earn its place.

- For each section, ask what the visitor loses if it is deleted. If nothing, delete it.
- Merge sections that say the same thing in different shapes.
- Cut copy by about half (`SL-40`, `CP-05`); keep the specifics.
- Remove filler badges, labels, icons and decorations (`DC-01`, `DC-02`, `DC-13`).
- Fewer choices per group (about four at most), progressive disclosure for the rest (`LY-03`).
