# XSlop animate

Plan motion before adding it. Load `rules/motion/README.md` and `recipes/RECIPES.md`.

Write a short motion plan:

- **Focal moment:** the one sequence that deserves authorship, if any, and why it belongs to this product.
- **Continuity:** layout or navigation changes that need explaining (shared elements, `MO-20`).
- **Feedback:** controls that need acknowledgement (`MO-04`, `MO-08`, `DC-20`).
- **Budget:** what is expensive, how often it runs, its reduced-motion version (`PF-21`, `AX-12`).

Timing: 100–150 ms feedback, 150–300 ms state changes, 300–500 ms overlays and view changes, 500–800 ms only for
a deliberate focal entrance. Exits faster than entrances (`MO-15`). No bounce on everyday UI (`MO-13`).
Content is visible before any animation runs (`SL-72`).
