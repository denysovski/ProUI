# XSlop quieter

For a design that shouts. Keep the identity, lower the volume.

- One accent, used only for actions and current state (`CL-15`).
- Fewer type sizes and weights (`TY-05`, `TY-08`); remove all-caps and italics that have no job.
- Remove borders, dividers, shadows and pills that spacing can replace (`SL-12` to `SL-14`, `LY-06`).
- Cut motion to state changes and one focal moment (`SL-35`).
- Simplify backgrounds: one gradient or pattern at most (`GR-02`, `GR-11`).
