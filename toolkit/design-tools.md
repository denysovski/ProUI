# Design tools by stage

A curated list of tools for the stages of a web project, mostly found through
[minitools.design](https://minitools.design), a directory of small design tools filtered by Backgrounds, 3D,
Gradients, Mockups, Typography, Colours, Utilities and Accessibility. The agent suggests a tool at the stage
where it helps; the user does the export when the tool needs a person at the controls.

## Brand and logos (before the design system)

- **GeoLogo**, **Logo Lattice**: geometric logo marks built on square or isometric grids, SVG/PNG export. Only
  as a starting sketch when the client has no logo; never invent a brand mark without asking.
- **Gridcraft**: presenting vector logo work with construction grids, for a brand case study.
- **Symbl**: testing how a mark reads at every size and contrast; use before making favicons (`PE-05`).
- **SVGL** (https://svgl.app): official SVG logos of well-known brands for "works with" rows (real ones only).

## Typography (design-system checkpoint)

- **Fontshare** (https://fontshare.com) and **Google Fonts** (https://fonts.google.com): free families.
- **Typewolf** (https://www.typewolf.com): what faces real sites use, pairings and alternatives to overused ones
  (`SL-59`).
- **Type Scale** (https://typescale.com), **Typescale AI**: modular scales and tokens (`TY-05`).
- **The Good Line-Height**: line heights on a baseline grid (`TY-11`).
- **Fontjoy** (https://fontjoy.com): pairing ideas to react to, not to accept blindly.
- **Wakamai Fondue** (https://wakamaifondue.com): what a font file supports (languages, figures, features)
  (`TY-18`, `TY-20`).
- **FontFreezer**: freezing variable-font settings into static files for smaller loads.

## Colour and gradients (type-and-colour checkpoint)

- **OKLCH** (https://oklch.com), **Realtime Colors** (https://www.realtimecolors.com): palettes previewed on a
  real page layout.
- **Huemint** (https://huemint.com), **Coolors** (https://coolors.co), **Color Hunt** (https://colorhunt.co):
  palette ideas, to be turned into roles (`CL-04`).
- Gradient tools: see `gradients.md` (Balsa UI Gradient Studio, Pryzm, ShaderGradient and more).
- **Who Can Use** (https://www.whocanuse.com), **Colorable**, **Colour contrast checker**: contrast for real
  people (`CL-09`).

## Shapes, patterns, icons

- See `shapes-and-backgrounds.md` (Book of Shapes, Hero Patterns, Get Waves).
- Icon sets that are not the default (`SL-29`): **Phosphor** (https://phosphoricons.com), **Tabler**
  (https://tabler.io/icons), **Iconoir** (https://iconoir.com). One set per site (`DC-12`).

## 3D (only when the style asks for it)

- **Spline** (https://spline.design): interactive 3D scenes, already in `TOOLKIT.md`.
- **Morflax Studio**, **Valessa**: 3D product and device compositions, materials, HDRI lighting, GLB export.
- **Poly Haven** (https://polyhaven.com): free CC0 HDRIs, textures and models for lighting a three.js scene.
- **glTF Report** (https://gltf.report): inspecting and compressing GLB files before they ship (`PF-21`).
- minitools 3D filter: Sticky (chrome, glass and foil wraps), Liquid Metal, Liquid Orb Editor, Glass, i3Dify.
  Use for one hero object, exported as an optimised image or video, not as a live scene by default.

## Motion

- **Easings editors**, **Springs Studio**: curves and motion tokens to put in `DESIGN.md` (`MO`).
- **Animista** (https://animista.net): CSS keyframe ideas; adapt timing to `MO` rules before using.

## Mockups and launch (final stage)

- **shots.so** (https://shots.so), **Presenta**, **Tokokino**, **Ultramock**, **Sliick**, **mckp.live**: the
  real site's screenshots placed in device frames for the README, case study and OG image (`PE-06`).
- **Frametic**: a website URL turned into a cinematic mockup video for launch posts.
- **AppScreen**: store-size screenshot sets if there is an app.
- **ray.so** (https://ray.so): code snippets as images for a developer-facing launch.

## Utilities

- **Squoosh** (https://squoosh.app): compressing and converting images by hand (`PF-01`).
- **SVGOMG**: optimising SVG.
- **Triim**: trimming transparent edges from PNG/WebP.
- **tldraw** (https://tldraw.com): quick wireframes and flow sketches at the outline checkpoint.
