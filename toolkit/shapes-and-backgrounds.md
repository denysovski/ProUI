# Shapes, patterns and backgrounds

Rules: `GR-11` to `GR-14`, `SL-56`, `SL-70`.

| Tool | URL | Use it for |
| --- | --- | --- |
| Book of Shapes | https://bookofshapes.com | free, generative, customisable SVG patterns by Nikolaj Sokolowski, in grid, radial, flow, noise, isometric, distortion, organic and physics families; tune live, download SVG or paste into Figma; free for commercial use (check the licence page) |
| Pryzm Studio | https://pryzm.design/studio | layering a pattern over a gradient or photo into one background image |
| SVG Doodles | https://svgdoodles.com | hand-drawn accents (underlines, arrows, scribbles), already in `TOOLKIT.md` |

| SVGOMG | https://jakearchibald.github.io/svgomg/ | optimising every SVG before it ships (`GR-13`) |
| minitools.design backgrounds filter | https://minitools.design | Dot Grid Builder, Durves (dot matrix, wave and grid patterns), Sinwaver, Tabbied, Marbler, Weaver, Cutting Mat Generator, Shape Divider App, Light Stroke Tails |

## How to use them well

- Pick one pattern family for the whole site and tune it to the palette at low contrast (`GR-11`).
- A pattern is a background, never the content. If the pattern is what you remember, it is too strong.
- Inline small SVGs; reference larger ones as files with `background-image` and a fixed `background-size`.
- Respect the source licence and keep a note of it in the README credits.
