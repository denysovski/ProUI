# Sitemaps by kind of site

> Which pages each kind of site needs, in the order of importance. Pick the row from the intake answer "What kind of website is it?", then cut anything the business cannot fill.

[Blueprints](README.md)

Pages in **bold** are expected by visitors; the rest are added when the content exists. Every site also gets
the launch pages from the [Launch Essentials Rulebook](../rules/launch/README.md): 404, privacy, terms where
needed, and company details (`PE-01`, `PE-08`, `PE-09`, `PE-16`).

## Service business (studio, clinic, trades, consultant, agency)

| Page | Job | Sections |
| --- | --- | --- |
| **Home** | say what you do, for whom, where; get the enquiry | hero with the main action, services overview, proof (clients, reviews, numbers), how it works, packages or "from" prices, FAQ, contact block |
| **Services** | one block or one page per service | what it includes, who it is for, duration or delivery, price or "from" price, result photos, a call to action per service |
| **Pricing or packages** | when services are sold as packages | three named packages from the real offer, what each includes, add-ons, FAQ about payment ([pricing.md](pricing.md)) |
| **Work, case studies or references** | prove it | real projects: problem, what was done, result, photos, client quote with permission |
| **About** | the people behind it | story in a paragraph, team with real photos, values shown by facts, certifications |
| **Contact** | make reaching you easy | phone, email, address, hours, form, map, response time ([contact.md](contact.md)) |
| Booking | when the service is booked online | calendar or booking tool, what happens next |
| FAQ | when questions repeat | grouped answers, link to contact |
| Blog or advice | when someone will write | articles that answer customer questions (SEO) |

## Company or B2B (manufacturer, firm, corporation)

| Page | Job |
| --- | --- |
| **Home** | position, main offerings, proof, routes for each audience (customers, partners, job seekers, press) |
| **Products or solutions** | overview, then one page per product line or industry |
| **Industries or customers** | when the same offer is sold to different sectors |
| **References and case studies** | named clients, results |
| **About** | history, leadership, locations, certifications, sustainability |
| **Careers** | open roles, benefits, process |
| **Contact** | departments, locations, sales and support routes ([contact.md](contact.md)) |
| News or press | releases, media kit, press contact |
| Downloads or documentation | catalogues, data sheets, manuals |
| Partners, investors | when relevant |

Information-heavy companies need a [fat footer](footer.md) and usually a search (`NV-06`).

## Product or SaaS

| Page | Job |
| --- | --- |
| **Home (landing page)** | the full [landing page](landing-page.md): promise, product, proof, pricing preview, FAQ, final CTA |
| **Product or features** | one page per major capability, with real screenshots or a demo (`SL-45`) |
| **Pricing** | tiers, billing toggle, comparison table, FAQ ([pricing.md](pricing.md)) |
| **Sign in / Sign up** | in the header, top right |
| Use cases or solutions | per role or industry |
| Customers | case studies, logos with permission |
| Integrations | when the product connects to others |
| Docs, changelog, status | for products with users already |
| Blog | product education, SEO |
| About, careers, security | trust for larger buyers |

## Shop

| Page | Job |
| --- | --- |
| **Home** | current collection or bestsellers, categories, shipping and returns promise |
| **Category / listing** | filters, sort, product cards with price and stock |
| **Product detail** | photos, price, variants, add to cart, delivery estimate, reviews, details and care |
| **Cart and checkout** | a cart drawer that sells honestly ([cart.md](cart.md), `PG-24`–`PG-28`), guest checkout first, full price early (`FO-08`, `FO-09`) |
| **Shipping, returns, payment** | one clear page each, linked from product pages and the footer |
| **Contact and order help** | order status, returns, email or chat |
| Lookbook | fashion and lifestyle shops: full-screen, tappable looks with shop the look ([lookbook.md](lookbook.md), `PG-29`, `PG-30`) |
| About or story | the maker, the materials |
| Account | orders, addresses, only when needed (`FO-15`) |

## Portfolio or creative work

| Page | Job |
| --- | --- |
| **Home** | the work itself, immediately; name and discipline in one line |
| **Work / project pages** | one page per project: context, role, images, result |
| **About** | bio, clients, awards, CV |
| **Contact** | email first, availability, social links |
| Services | when the portfolio sells a service; then add packages ([pricing.md](pricing.md)) |
| Shop, prints | when relevant |

## Restaurant, café, bar

| Page | Job |
| --- | --- |
| **Home** | food photos, opening hours, address, reserve or order button |
| **Menu** | real HTML text with prices, allergens, not a PDF only |
| **Reservations** | booking tool or phone |
| **Location and hours** | map, transport, parking, accessibility |
| Events, private dining, gift cards | when offered |
| About | the chef, the story |

## Personal site or blog

| Page | Job |
| --- | --- |
| **Home** | who you are in a sentence, latest writing or work |
| **Writing / articles** | list with dates and topics, readable article template |
| **About** | longer bio, photo, contact |
| Projects, talks, newsletter | when they exist |

## Size guide

| Intake answer | Build |
| --- | --- |
| One page | the landing page with anchor navigation; services, pricing and contact become sections |
| Several pages | the bold pages above; the rest only with real content |
| Several languages | the same sitemap per language, a language switch in the header and footer (`LO`) |
