# Read

The visitor came to understand something. Type, measure and wayfinding matter more than anything else.

## Defaults

- body 17–20 px, line length 60–72 characters, line height about 1.6 (`TY-06`, `TY-10`, `TY-11`)
- clear heading hierarchy that works as an outline; a table of contents for long pages; anchor links on
  headings (`SEO-08`)
- generous vertical rhythm, more space above headings than below (`TY-13`)
- code blocks, tables, footnotes and images styled as part of the reading, not as cards
- reading progress or "on this page" navigation for long documents, previous/next at the end
- quiet colour: Restrained, with the accent for links only (`CL-15`)

## Avoid

decorative motion, sticky elements that cover text, pop-ups that interrupt reading, tiny grey text.

## Rules that weigh most

`TY`, `LY`, `AX`, `SEO`, `CP-05`, `CP-06`, `PF-01`, `PF-02`.
