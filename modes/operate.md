# Operate

The visitor is in a task. The interface should disappear into it. Familiar beats surprising.

## The style lends only

type, palette, density and one signature move (for example service health drawn as a transit map, a schedule
set in a timetable's rhythm). It never supplies the layout, the navigation model or the controls.

## Defaults

- `CL-01` Restrained palette with a second neutral for chrome (`DB-03`); colour does real jobs: state, data
  series, selection
- one type family, fixed `rem` scale, ratio about 1.125–1.2 (`TY-02`, `TY-05`, `TY-07`)
- standard controls and navigation (`IX-02`, `DB-02`)
- transitions 150–250 ms, no page-load choreography, motion only for state (`DB-15`)
- every component with every state (`IX-01`), skeleton loading, teaching empty states (`DB-11`, `DB-12`)

## Self-check

With the logo covered: does it read as a working product of its category, could someone do the task from it,
and is it at least as clean as the best product in the category, and more distinctive?

## Rules that weigh most

`DB`, `IX`, `ST`, `AX`, `TY`, `CL`, `LY`, `CP-10` to `CP-13`, `PF-08` to `PF-10`.
